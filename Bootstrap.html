1. The Grid System

Bootstrap divides every row into 12 columns. Use classes like col-6 (half), col-4 (third), or col-md-3 (quarter on medium+ screens). The grid is responsive by default.

5. Modal (Popup)

A Modal is a dialog box that overlays the page. Bootstrap handles all the show/hide logic via data-bs-toggle="modal". No JavaScript required!

Bootstrap Modal

This modal was triggered with just one HTML attribute:

data-bs-toggle="modal" data-bs-target="#demoModal"

Bootstrap's JavaScript bundle handles everything else automatically.

6. Bootstrap Forms

Bootstrap styles form inputs with form-control, labels with form-label, and wraps them in mb-3 for consistent spacing.
