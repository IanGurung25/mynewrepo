What Is Semantic HTML?

Semantic HTML uses tags that describe the meaning of the content, not just its appearance. This improves accessibility, SEO, and readability. Instead of using <div> for everything, we use tags like <header>, <nav>, <main>, <article>, and <footer>.

<body>
<header> ← site title & branding
<nav> ← navigation links
<main>
<section id="semantic"> ← grouped content
<h2> ← sub-heading
<p> ← paragraph
</section>
</main>
<footer> ← copyright / contact
</body>

Common HTML Tags

Every tag has a purpose. Here are the most commonly used ones:

<h1> – <h6> <p> <a href=""> <img src=""> <ul> <li> <div> <span> <strong> <em> <form> <input> <table> <section> <article>

HTML Forms

Forms collect user input. Each <input> has a type attribute that controls what kind of data is accepted.

HTML Tables

Tables use <table>, <thead>, <tbody>, <tr> (row), <th> (header cell), and <td> (data cell).

Tag Full Name Purpose Self-Closing?
<p> Paragraph Block of text No
<img> Image Embed an image Yes
<a> Anchor Hyperlink No
<br> Line Break Forced line break Yes
<input> Input Form field Yes
