1. The Box Model

Every HTML element is a rectangular box made of 4 layers: Content → Padding → Border → Margin. Understanding this is key to controlling layout and spacing.

4. Pseudo-classes & Transitions

:hover applies styles when the user hovers over an element. transition makes the style change animate smoothly over time. ::before inserts a decorative element before the content.

5. CSS Animations & @keyframes

@keyframes defines the steps of an animation. animation: applies it to an element with duration, timing, and repeat count.
